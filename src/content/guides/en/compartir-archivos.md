Email rejects large attachments and WhatsApp compresses or truncates video. For a big PDF, a family video, or a work folder, a controlled link usually beats stuffing the file into a message.

## 1. Upload to a stable place

Store the file somewhere you can open again. Avoid “send and forget” in fleeting chats if you need it later.

## 2. Share a link, not the whole file

Create a download or view link. The message (email, WhatsApp, SMS) then carries only the address, not megabytes of attachment.

## 3. Limit who can access

For sensitive content, add a password, expiry, or named people only. Test the link yourself before you send it.

## 4. Explain how to open it

A short note helps: “Link valid for a few days; if it asks for a password, I will send it separately.” Fewer improvised support threads and fewer resends.

## 5. Revoke when finished

After the recipient has downloaded the file, turn the link off if your service allows it. That avoids an open door left by mistake.

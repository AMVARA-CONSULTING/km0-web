<section class="doc-lead-block">
  <p class="doc-block-title">Einführung</p>
  <p class="doc-lead">Sie können eine Datei oder einen Ordner mit einer anderen KM0-Cloud-Person oder mit jemandem außerhalb Ihrer Organisation über einen öffentlichen Link teilen. Diese Anleitung erklärt beide Fälle im Browser.</p>
</section>

<section class="doc-block">
  <p class="doc-block-title">Voraussetzungen</p>
  <h2 class="doc-block-heading">Bevor Sie starten</h2>
  <ul class="doc-list">
    <li>Angemeldet bei <a href="https://cloud.km0digital.com/">KM0 Cloud</a>.</li>
    <li>Berechtigung zum Teilen der Datei oder des Ordners (in der Regel sind Sie Eigentümer oder haben Bearbeitungsrechte).</li>
  </ul>
  <p class="doc-block-intro">Falls Sie noch nicht angemeldet sind, siehe das Tutorial <a href="/de/tutorials/getting-started-web/">Erste Schritte im Browser</a>.</p>
</section>

<section class="doc-block doc-block-alt">
  <p class="doc-block-title">Schritt 1</p>
  <h2 class="doc-block-heading">Freigabebereich öffnen</h2>
  <ol class="doc-list">
    <li>Finden Sie die Datei oder den Ordner in Ihrem persönlichen Bereich oder in einem Space.</li>
    <li>Klicken Sie auf das Drei-Punkte-Menü neben dem Namen.</li>
    <li>Wählen Sie <strong>Teilen</strong>.</li>
  </ol>
  <p class="doc-block-intro">Rechts öffnet sich eine Seitenleiste.</p>
</section>

<section class="doc-block">
  <p class="doc-block-title">Schritt 2</p>
  <h2 class="doc-block-heading">Mit jemandem in der Organisation teilen</h2>
  <ol class="doc-list">
    <li>Öffnen Sie im Panel den Bereich <strong>Interne Freigabe</strong>.</li>
    <li>Geben Sie mindestens drei Zeichen in das Suchfeld ein, um Benutzer oder Gruppen zu finden.</li>
    <li>Wählen Sie die Person oder Gruppe aus den Vorschlägen.</li>
    <li>Legen Sie die Zugriffsrechte fest:
      <ul class="doc-list">
        <li><strong>Kann anzeigen:</strong> nur Lesen und Herunterladen.</li>
        <li><strong>Kann hochladen:</strong> Lesen und Hochladen in freigegebene Ordner.</li>
        <li><strong>Kann bearbeiten:</strong> Anzeigen, Hochladen, Erstellen, Ändern und Löschen.</li>
      </ul>
    </li>
    <li>Klicken Sie auf <strong>Teilen</strong>.</li>
  </ol>
  <p class="doc-block-intro">Die Person erscheint unter <strong>Geteilt mit</strong> im gleichen Panel.</p>
</section>

<section class="doc-block doc-block-alt">
  <p class="doc-block-title">Schritt 3</p>
  <h2 class="doc-block-heading">Außerhalb der Organisation teilen (öffentlicher Link)</h2>
  <ol class="doc-list">
    <li>Scrollen Sie im Freigabepanel zu <strong>Öffentliche Links</strong>.</li>
    <li>Klicken Sie auf <strong>Link hinzufügen</strong>.</li>
    <li>Wählen Sie den Zugriffstyp:
      <ul class="doc-list">
        <li><strong>Kann anzeigen:</strong> Anzeigen und Herunterladen, ohne Bearbeitung.</li>
        <li><strong>Kann bearbeiten:</strong> Anzeigen, Herunterladen, Bearbeiten, Löschen und Hochladen.</li>
        <li><strong>File Drop (geheim):</strong> nur Hochladen, ohne vorhandene Inhalte zu sehen.</li>
      </ul>
    </li>
    <li>Optional: Geben Sie ein Passwort im Feld <strong>Passwort</strong> ein. Wenn der Server eines verlangt, müssen Sie es vor dem Speichern setzen.</li>
    <li>Optional: Setzen Sie ein <strong>Ablaufdatum</strong>, wenn der Link später nicht mehr funktionieren soll.</li>
    <li>Klicken Sie auf <strong>Link kopieren</strong> und senden Sie die URL (und das Passwort, falls gesetzt) über Ihren bevorzugten Kanal.</li>
  </ol>
</section>

<section class="doc-block">
  <p class="doc-block-title">Schritt 4</p>
  <h2 class="doc-block-heading">Zugriff entfernen oder ändern</h2>
  <ul class="doc-list">
    <li><strong>Interne Freigabe:</strong> Öffnen Sie erneut <strong>Teilen</strong>, finden Sie die Person unter <strong>Geteilt mit</strong>, öffnen Sie deren Drei-Punkte-Menü und wählen Sie <strong>Freigabe entfernen</strong>.</li>
    <li><strong>Öffentlicher Link:</strong> Unter <strong>Öffentliche Links</strong> öffnen Sie das Link-Menü, um Berechtigungen, Passwort oder Ablauf zu ändern oder den Link zu löschen.</li>
  </ul>
  <p class="doc-block-intro">Nach dem Entfernen kann die Person den Inhalt sofort nicht mehr sehen.</p>
</section>

<section class="doc-block doc-block-alt">
  <p class="doc-block-title">Häufige Probleme</p>
  <h2 class="doc-block-heading">Fehlerbehebung</h2>
  <ul class="doc-list">
    <li><strong>Benutzer nicht gefunden:</strong> Prüfen Sie, ob Sie mindestens drei Zeichen eingegeben haben und die Person ein KM0-Cloud-Konto hat.</li>
    <li><strong>Der Link verlangt ein Passwort, das ich nicht kenne:</strong> Öffnen Sie das Freigabepanel, bearbeiten Sie den Link und setzen Sie ein neues Passwort.</li>
    <li><strong>Keine Option Teilen:</strong> Möglicherweise haben Sie keine Berechtigung für diese Datei; bitten Sie den Eigentümer oder Space-Manager um Zugriff.</li>
  </ul>
  <p class="doc-block-intro">Für Zugriff auf einen ganzen Space (nicht nur eine Datei) siehe das Tutorial <a href="/de/tutorials/space-permissions/">Space-Berechtigungen</a>.</p>
</section>
